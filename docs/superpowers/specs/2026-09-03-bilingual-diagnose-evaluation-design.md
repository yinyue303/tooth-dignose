# 双语诊断报告评估设计

## 目标

让 `models/dignose.py` 根据测试样本语言生成同语言报告，并分别汇总中英文评估指标。最终指标只打印到标准输出，由作业系统写入日志；脚本不再生成独立的 `_metrics.txt` 汇总文件。

## 数据语言标记

修改 `dataset/excel/test-diagnostic.xlsx`，在现有 `images` 列后新增 `language` 列：

- `q` 为中文时写入整数 `0`；
- `q` 为英文时写入整数 `1`。

语言判断只读取 `q`，不读取参考答案 `a`。当前 1799 条测试数据中，`q` 和 `a` 的语言类别完全一致。写入后校验总行数不变、`language` 无空值且只包含 `0` 和 `1`。

## 提示词与生成

保留中文九段式提示词，并新增结构对应的英文提示词。处理每条样本时读取 `language`：

- `0` 使用中文系统提示词，生成中文报告；
- `1` 使用英文系统提示词，生成英文报告；
- 其他值立即报错，避免静默使用错误提示词。

同一个推理批次可以包含中英文样本，每条消息独立插入对应的系统提示词。

## 指标计算

中文样本：

- 使用字符级 tokenizer 计算 BLEU-4；
- 计算 Gemma 余弦相似度；
- 不计算 METEOR。

英文样本：

- 使用 `wordpunct_tokenize` 计算 BLEU-4；
- 使用 `wordpunct_tokenize` 计算 METEOR；
- 计算 Gemma 余弦相似度。

中文字符级 tokenizer 将每个汉字作为独立 token，同时保留连续英文、数字、牙位和疾病编码信息。计算前校验中文、英文两组均非空，并校验参考答案和预测数量一致。

## 输出

继续保存原有逐样本预测结果文件。最终平均指标不写入单独文件，只通过 `print()` 输出：

```text
最终评估结果：

英文样本数量：<count>
BLEU：<score>
METEOR：<score>
Cosine Similarity：<score>

中文样本数量：<count>
BLEU：<score>
Cosine Similarity：<score>
```

不计算或输出中英文混合总平均值。
